# ShareGroupHeartbeat (API key 76)

Intended range: v1.

| Version | Request                                                                              | Response                                                  |
| ------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------- |
| v1      | Initial share group member state and subscriptions; member IDs are client-generated. | Initial member epoch, heartbeat interval, and assignment. |

> v0 was the early access version of KIP-932 in Apache Kafka 4.0 and was removed in Apache Kafka 4.1, so v1 is the minimum supported version.
